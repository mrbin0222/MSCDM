# Remaining release dependencies

This package is ready for author code review, not represented as a completely validated public release.

## Required before public release

1. MIT licensing and the MSCDM contributors copyright notice are in place. Retain applicable third-party notices when publishing.
2. Keep the release scope explicit: no study-trained weights or third-party pretrained models are uploaded, and raw data are obtained directly from providers. These are settled publication choices, not missing upload tasks. Document the required user-supplied assets and the limits of reproducing the exact archived models without their initialization/checkpoints.
3. Verify the included provider converters against the complete original inputs. The source code for all four provider families has been collected and its CLIs loaded on the server; full dataset conversion was not rerun. No original data are bundled.
4. Validate full-resolution segmentation preparation/generation end to end with the real CTC inputs. The code now starts from the converted CTC manifest and supports planning without a historical generated cache; the metadata/preparation path passes constructed-fixture tests.
5. Run fresh Linux generation/evaluation and Cellpose 4.2 dependency installations, followed by checkpoint-backed full-resolution image inference and an authorized small segmentation workflow. Existing-server-environment CLI/basic tests, isolated-target installation and strict foreground checkpoint loading now pass; these do not constitute a fresh dependency install or downstream reproduction.
6. Check the new full-resolution foreground adapter against the original image-inference call with identical weights, masks, backgrounds and noise. The extracted core tensor path already agrees bitwise with the original on constructed RPE/3T3/same-class inputs; the full public image adapter remains unverified.

## Further hardening

- Convert all recorded paper settings into validated per-entry CLI configurations; currently JSON metadata and actual CLI options are both provided, with commands mapped in docs/experiments.md.
- Remove unused development branches from shared training utilities only after behavioral tests. Public entry names are functional; checkpoint/schema strings and some legacy optional settings remain for compatibility.
- The published foreground evaluator training code is extracted, but its fixed labels and vocabulary are included in the compact catalog, with runtime manifests generated by materialize_manifests.py; all weight assets and final evaluation selection must be checked alongside its final selection protocol before claiming turnkey evaluation.
- Preserve exact dataset ownership/licensing decisions for metadata and any future examples. Current examples are constructed and contain no microscopy data.
